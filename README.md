<h3>How to install the website</h3>

<p>To install the website, you have to install VS code</p>
<p>Install the Final file and move that into VS code</p>
<hr>
<br>
<h3>installations in VS Code</h3>
<p>For VS code, install pandas and flask</p>
<p>once installed, run the python file. Ensure you are in the right file directory(use cd [filename] to get into the directory)</p>
<hr>
<br>
<p>Once in Final, run the python file by typing python website.py.</p>
<p>This will run the website and have the game description and a wiki for the game</p>
<hr>
<br>
<h3>You don't need to install anything to run the game</h3>
<p>The zip file that you download will have a .exe file for you to run. It would have been web based, but we couldn't get it to work</p>
<hr>
<br>
<h3>So how do I play?</h3>
<p>All of the information you need to play the game is in the html files</p>
